# 📚 Resource Hub – Centralized Learning Materials App

**Resource Hub** is a cross-platform mobile and web application built with **Flutter** that serves as a centralized platform to manage, share, and access educational resources such as documents, links, videos, and notes.

---

## 🚀 Features

- 🗂️ Categorized resource listing (e.g., Notes, PDFs, Links, Videos)
- 🔍 Search functionality to quickly find resources
- 🌐 Works on Android, iOS, Web, Windows, Linux, and macOS
- 🎯 Simple and intuitive UI for fast access

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vishalvnair124/resource_hub.git
cd resource_hub
```

### 2. Install dependencies

```bash
flutter pub get
```

### 3. Run the app

To run on a specific platform:

```bash
flutter run -d <device_id>     # e.g., chrome, android emulator, windows
```

To see all connected devices:

```bash
flutter devices
```
